# Lessons

One line each, added through PRs by pipeline runs and curated by a maintainer. Workers read this before every run.

- wporg-theme-directory: run `TEXTDOMAIN=wporg-themes composer exec update-configs` before `composer lint`.
- wordpress.org: the plugin-directory test env maps the wporg-plugins-2024 theme, so its template parts can be tested from `plugin-directory/tests` via `WP_CONTENT_DIR . '/themes/wporg-plugins-2024/...'`; `wp_kses()` output lowercases and re-quotes attributes, so assert with `WP_HTML_Tag_Processor`, not raw strings.
- wordpress.org: Trac config/templates (`trac.wordpress.org/`) can be checked locally: `pip install` the Trac 1.6 sdist into a venv, `trac-admin <env> initenv`, add `file = <repo>/trac.wordpress.org/conf/common.ini` under `[inherit]`, then run `tracd` and curl a page; note `initenv` writes every default into the env's own `trac.ini`, which overrides inherited values.
- wordcamp.org: to run PHPUnit here, start `mariadb:lts` in docker on 3306, run `.docker/bin/install-wp-tests.sh wcorg_test root root 127.0.0.1:3306 latest true`, unzip the GatherPress release CI pins into `plugins/`, build `wporg-groups-frontend`, and `composer update` from a temp copy of `composer-dev.json` without `wporg-profiles-wp-activity-notifier` (meta.svn is blocked); set phpcs `installed_paths` by hand since Composer plugins are disabled. The "WordCamp Groups Network" suite (`mu-plugins/groups/tests`) holds the groups-site theme tests.
- Meta Trac: `getTicket`'s default comment limit drops the early thread, where committers give direction; pass `"commentLimit": 500`.
- wordpress.org: a fatal `Undefined constant WPORG_PLUGIN_DIRECTORY_BLOGID` in the plugin-directory wp-env means a stale database; run `wp-env destroy` and start again.
- wordpress.org: `support-helphub` was synced from the archived WordPress/wporg-documentation-2022 repo, and a sync from there can delete files that exist only in Meta; fix it in Meta.
- WordPress 7.2's kses decodes numeric character references (r64233): content encoded before kses (`&#91;`, `&#045;`) comes back decoded, so encode after kses.
- Props Bot: `@propsbot add <wporg>@git.wordpress.org` credits a WordPress.org user, with or without a GitHub account.
- wporg-parent-2021: wpackagist.org is blocked by the proxy, so `composer install` fails; for PHPUnit, `composer update --ignore-platform-req=php` from a temp `COMPOSER=` copy of composer.json without the wpackagist repo, `wpackagist-plugin/*` and `wporg/wporg-repo-tools`, copy `vendor/wporg/wporg-mu-plugins` to `source/wp-content/mu-plugins/`, and start `mariadb:lts` on 3306 (root/root, `wordpress_test`). Lint CSS fails on trunk too: the repo-tools trunk `.stylelintrc` needs a newer `@wordpress/stylelint-config` than the repo pins.
- pattern-directory: `bin/check`'s PHPUnit step needs MySQL; start `mariadb:lts` on 3306 (root/root, `wordpress_test`) first. The wp-env site caches PHP for a few seconds, so wait before re-requesting a page after swapping files for before/after screenshots.
